### A simple EXE that lets you open any version of The Choicer Voicer in one place, plus seamlessly install mods by dragging and dropping your zip/rar file(s) into the launcher's drag-and-drop box.  Also allows mod browsing, installed mod browser, and a dub rendering tool.

## How to Use (Basic Functioning)
The launcher needs to be placed in a directory like this:
- The Choicer Voicer Launcher.exe
- Compatibility (Folder)
  - 0.#.#
    - 0.#.# EXE
    - display.txt (You need to type in what you want this EXE to display as in the launcher via this file.)
- Compatibility (Folder)
  - 0.#.#
    - 0.#.# EXE
    - display.txt (You need to type in what you want this EXE to display as in the launcher via this file.)

Or, you can add the version inside the launcher by uploading the EXE into the right drop-in box.
   
You can add as many versions as you want in the normal and compatibility folders in the same format, since the launcher includes a drop-down menu for both editions that shows all the versions you've added in the respective folders.

You can also add the launcher to Steam as a Non-Steam Game, and opening it will open the launcher, and opening one of the games you've added will still work seamlessly.
## How To Mod
Inside the launcher, there are four points of interest below the basic functionality:
- Main Launch Page
- Mod Browser
- Drag 'n Drop Box
- Folder Icon

The main and most recommended modding method is the Mod Browser, which allows you to search for and find any mod for the game and also to download them all in the same application.
<img width="820" height="648" alt="Screenshot 2026-10-18 162453" src="https://github.com/user-attachments/assets/fccaa657-326f-425f-9660-347e54123743" />

The drag-and-drop box is an alternative method if you instead have a link to a mod you'd like to download. Drag-and-drop is available at the top of the browsing tab. (GameBanana links have to include https:// at the beginning of it, or it will NOT work.)

(NOTICE): If a mod has a weirder setup, like a readme.txt next to where the main folder is in the zip, it may not work as intended, so make sure it worked properly by pressing the Folder Icon to enter your mods folder before double-checking if it extracted correctly.)

You can also see your installed mods in the Installed Mods window, where you can move mods to another folder or redirect to the GameBanana page you downloaded it from (Only works if downloaded using the 'Browse Mods' feature)
<img width="820" height="648" alt="Screenshot 2026-10-18 162503" src="https://github.com/user-attachments/assets/4d14262f-64e2-488d-a03a-b7079ed8b896" />

The new Dub Renderer can automatically piece your finished dubs together into an MP4 file to a destination of your choosing. Special thanks to TDTLuv for the code used to add this into the launcher.
<img width="820" height="648" alt="Screenshot 2026-10-18 162521" src="https://github.com/user-attachments/assets/a895ab46-544e-4803-8a2a-69e9c9979432" />

In the settings tab you're able to change the theme and theme color, music toggle and the volume, open your modding folder, and also view the readme.md, credits, and information of the application.
